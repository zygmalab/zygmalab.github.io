# ZYGMA — Advanced Dental Lab · zygmalab.com

Static site for ZYGMA™ (Tampa, FL). No build step: the files in this folder are the site.

- `index.html` — home (Register / Lab Rx / Upload / Quote, programs, education, about)
- `zygma-register.html` — doctor registration (unlocks prices)
- `zygma-rx.html` — online Lab Rx
- `zygma-price.html` — Price Experience + golden rules
- `zygma-lab-rx-paper.pdf`, `zygma-price-list.pdf` — printable versions
- `netlify.toml` — hosting headers (Netlify)

Every push to `main` is published automatically.
